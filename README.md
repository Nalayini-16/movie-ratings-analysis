# Movie Ratings Analysis

Exploratory data analysis of the TMDB 5000 Movies dataset to uncover
trends in ratings, budgets, revenue, and genres.

## Goals
- Explore rating distribution and trends over time
- Analyze relationship between budget, revenue, and rating
- Compare genres and identify top-performing directors/actors

## Tech Stack
- Python (pandas, matplotlib, seaborn)
- Jupyter Notebook

## Project Structure
- data/ - raw and cleaned datasets
- notebooks/ - analysis notebooks
- src/ - reusable helper functions
- visuals/ - exported charts
